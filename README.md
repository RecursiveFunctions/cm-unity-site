# CMUnity

The website for **CMUnity**, an official Carnegie Mellon University student
organization. CMUnity's mission: turn a campus of strangers into a community of
friends — *more than just a connection.*

The work serves three pillars:

1. **Friendship** — reshaping the social network by forming new bonds across
   the groups that normally never meet.
2. **Discourse** — increasing substantive conversation on philosophy, politics,
   religion, culture, and the human condition. Carried through our Discord and
   General Body Meetings (GBMs).
3. **Kindness & care** — genuine kindness and direct care for neighbors.

## Site

Static site built with Jekyll + Tailwind (CDN), deployed via GitHub Pages on a
custom domain.

- **Live:** https://cm-unity.org
- `index.html` — home page
- `brand/` — brand & web design specification (designer handoff)
- `debates/` — archived content **not affiliated with CMUnity**; retained in the
  repo for history only and intentionally unlinked from the site.
